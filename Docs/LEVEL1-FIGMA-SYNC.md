## 布局数据

`Level1Map` 是两个场景的共享布局来源，坐标换算为 `x = (设计 x - 330) × 0.04`，`z = (201 - 设计 y) × 0.04`。保留画板 874 × 402 的横向比例、三个不等宽 ramp、左侧设施次序和共享 taxiway 主干。`AirportWorld` 直接使用同一组矩形和多边形创建地面。

- `road gorup`：6 个矩形作为一个道路联合区域处理。车辆尺寸约束施加到联合区域的外边缘，拼接接缝不是墙。
- `pavement group`：5 个矩形。Ramp 3 的人行路线先经过设计坐标 `x=198` 的纵向段，再沿中间 ramp 下边缘向东；该纵向段位于道路内部，按共享区域处理，车辆遇到旅客让行。
- `taxiway group`：9 块矩形/多边形，包含原稿旋转角度，单独服务飞机。
- 中间 ramp 的西侧延伸保留为车辆作业通道，飞机占用区围绕实际停机位置判断，不再用旧的统一 x 截断线。

## 回归检查

`LevelLayoutValidation.Validate` 在 Unity 中检查所有站点到三个 ramp 的车辆路径、拼接处车辆完整占地、三条人行路径、飞机地面路径以及 ramp 3 的共享人行段。`LevelLayoutValidation.CaptureTopDown` 从保存的 MainLoop 场景重新加载并生成俯视图，方便与原始 SVG 对照。

验证结果以 `Evidence` 中的最新输出和本次任务说明为准。算法检查、场景重载与视觉截图不能代替双人手感验收。

## 飞机进出与结果

飞机模型的机头是本地 +X。两场景统一使用 `AircraftMotion` 将机头对齐实际路径切线；入场后保持最后一段的朝向。离场先沿反向路径推出 ramp，在滑行道上通过曲线倒车调整方向，短暂停顿后向前滑行，再沿跑道末段方向加速起飞。MainLoop 的入场/出场时间调整为 8/10 秒，以便分辨这些阶段。
