### 1.1 场景引用事故记录与教训

`MainLoop.unity` 的脚本绑定（MainLoopGame）与全部 88 个网格/材质引用曾整体断裂。表面原因：一批 `.meta` 的 guid 字段是**团结编辑器自己的非十六进制编码**（形如 `Xikfti2v…=`），与旧场景文件中记录的十六进制引用不一致。

**教训（写入开发约定）：**

- 团结 1.6.x 写出的 `.meta` guid 不是标准 32 位十六进制。**不要**用 Unity 原版格式标准去判定其非法，更不要手工改写 `.meta`——本次尝试解码证实该编码不可逆推回 hex。
- 场景/资产的修复路径是**让编辑器重建**（`MainLoopBuilder.CreateScene` 重新生成并保存全部资产），而不是手改 YAML。
- `Assets/Generated/` 是构建产物，可随时删除重建；它的事故不影响源码。

### 1.2 试玩失败 "Wrong vehicle acquired for task 0" 根因

- 旧证据堆栈行号与当前源码不一致，但**故障在当前代码稳定复现**（修复前 batchmode 重跑，同一报错）。
- 根因：车辆初始停车位距站点中心 1.5m，恰在站点交互半径（1.5m）边界。玩家从登机口方向接近餐车时，停点距餐食站 ≈1.40m < 1.5m，`Act()` 中"下单备餐"分支判定先于"获取车辆"，点按被站点吞掉。
- 修复：`MainLoopBuilder` 停车位偏移 1.5m → **2.4m**，与试玩脚本自身的"清位停车"距离一致。已重建场景验证引用完整。
- 由此固化为关卡规则：**站点交互半径 1.5m、车辆获取半径 1.65m，停车位与站点中心距 ≥ 2.4m，禁止两半径重叠**（§3）。
- 残余验证项：交互试玩（`MainLoopPlaytest`）在 batchmode 下因 `EditorApplication.update` 空转无法无头执行，需在 GUI 编辑器菜单 `Palm Bay → Verify main loop in Play Mode` 人工跑一遍确认修复生效。

## 3. 关键状态与规则（已定稿 2026-09-21，用户确认按建议值；取消读条/送错/燃油流程/漫油四项 2026-10-01 更新定稿；燃油流程与漫油 2026-10-05 按 M3.3r 简化）

**任务状态机**：待完成 →（按住进行/等待）→ 完成 / 失败。表现层需覆盖：默认、接近高亮、可交互、按住进行、被占用、等待、完成、失败、断线、禁用、恢复（M1 落视觉，M3 逐项落逻辑）。

| 规则 | M0 基线 |
|---|---|
| 交互占位 | 站点半径 1.5m / 车辆获取半径 1.65m / 停车位距站点 ≥ 2.4m，半径不重叠 |
| 占用 | 车辆同时只有一个 owner；bot 与真人同一操作接口、同一占用限制，不绕过资源竞争 |
| 取消 | 已装物品与已转移燃油保留；未完成动作停止；释放占用不复制资源。读条 2026-10-01 定稿：**餐食、行李取消后读条清零不保留；燃油、登机取消后进度保留，可从中断处继续加注/放行** |
| 送错 | 送错行李 = **误接收航班**的行李任务**永久失败**（不额外扣分；"该航班"指接收航班，2026-10-01 定稿）。原属航班的行李任务与实物行李去向在 M3.2 细化 |
| 完成与归零同刻 | 权威模拟时间戳裁定；完成时刻 ≤ 截止时刻计完成；同一状态推进步骤内处理 |
| 归零 | 停止一切移动与交互输入；已完成任务与得分保留 |
| 单航班逾期 | 任务失败/完成各自保留，飞机照常离场、机位释放；不设"整局失败" |
| 航班前置 | 下客 → 到达行李卸回 → 餐食/燃油 → 上客/装货；demo 的局部前置不作最终规则 |
| 燃油流程 | 2026-10-01 定稿站内资源库 + 油车最后一公里；**2026-10-05 M3.3r 简化定稿**：全部单次点按、无长按。站内（油车停站边）：点油站拿枪 → 点油车插枪 → 点阀门开阀，油车自动注油 → 再点阀门关阀，插在车上的油枪自动归位到油站；站内油枪永不随车离站。机位：点油车取车载油管 → 点飞机接管并自动注油 → 再点飞机断开，油管自动收回。阀门开着、站内油枪插在车上或车载油管不在车上时不可驾驶；驾驶中无法操作油枪、油管与阀门；单人可完整完成 |
| 登机口 | 采用左侧登机口（与 F6 及配图一致）；若支持关闭，仅停止新放行，已出发旅客继续 |
| 机位 | 首关 2 个可用机位 + 5 架错峰，第 3 机位作环境预留 |
| 镜头 | 局内斜视、结算/回放顶部俯视；M1 实际构图确认 |
| 星级 | 1/2/4 架 → 1/2/3 星为初始调参值，验收前冻结 |
| 漫油 | 随 M3.3 燃油交付（2026-10-01 纳入；2026-10-05 M3.3r 定稿）：阀门开着而油枪未插车立即漫油；油车满箱仍开阀或飞机加满仍接管，持续 2 秒宽限后漫油。油渍使油车减速、需徒步清理；不消耗站内储备与油车储量，不判任务失败 |
| bot 记忆 | 本地持久化 JSON（每设备）：累计共同局数、完成架数、玩家四类任务实际完成计数、上次同玩日期。用途：bot 分工时优先把玩家常做任务让给玩家；大厅展示"你们一起送走了 N 架"。**不记录语音与聊天内容** |

**联机预立约定（M2/M3 前不得违反）**：单一权威端裁定任务/占用/航班/结算，客户端提交操作意图；账号、参局身份、玩家、车辆、任务、航班均用稳定 ID；网络与回放不保存 Unity 对象引用。
